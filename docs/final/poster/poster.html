Headline

An LLM agent that checks, fixes and asks before it answers gets 95.5% of 200 questions on messy tables right, against 46.5% for a single LLM call, and never damaged a valid cell.

DataSage95.5%
Single LLM call46.5%

01

Problem

#SILENT!
Messy CSV and Excel files quietly change answers.
#MISSED!
Fixed cleaning scripts miss things they were not written for.
#NOLOG!
A single LLM call edits data it shouldn't and leaves no record.
