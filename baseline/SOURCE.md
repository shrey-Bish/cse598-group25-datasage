# Source of this baseline

These files are the stakeholder's runnable baseline, copied without changes from
https://github.com/VB914/DataSage at commit `4b1df80` ("Update repository setup instructions"),
written by Vyshanth Buddani. `README.md` in this folder is his original README.

The generated `outputs/` and `screenshots/` folders were not copied. Running the
baseline or `smoke_test.py` recreates `outputs/`, which is ignored by git.

We keep this copy so the final agent can be compared against the exact same baseline.
Changes to the baseline, if any, will go in separate commits and be described here.
