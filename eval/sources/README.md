# Source data

- `penguins.csv`: Palmer Penguins (Horst, Hill and Gorman, 2020), from
  https://github.com/allisonhorst/palmerpenguins (`inst/extdata/penguins.csv`).
  License: CC0-1.0 (public domain). Only complete rows are used as the clean base for the
  planted-error benchmark.

The sales tables are synthetic. They are generated by `eval/generate.py` in the format of the
stakeholder's `messy_sales.csv` (Order_ID, Date, Product, Category, Quantity, Price, Region, Revenue).
